# The Big Book of Small Python Projects - Complete Project Guide

Welcome to your guide for all 81 Python projects! Each project is a complete, standalone program that teaches key programming concepts while being fun to build and play with.

## 📖 Book Companion

**Full book with detailed explanations:** https://inventwithpython.com/bigbookpython/

Each project number below links to its chapter in the companion book, where you'll find:
- Detailed explanations of how the code works
- Programming concepts and patterns used
- Variations and extension ideas
- Complete source code with comments

## 🎮 How to Use This Guide

1. **Browse by category** below to find projects that interest you
2. **Check the tags** to find projects at your skill level (tiny, short, large)
3. **Run projects** using: `python project_runner.py --run PROJECT_NAME`
4. **Read the book chapter** for detailed explanations
5. **Experiment** by modifying the code in `my_projects/`
